# SCRawCheat - Автоматизация для GTA 5 RP

Бот-хелпер для автоматизации работ в игре!

# Установка Python

Перейдите по ссылке: https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe

Откройте файл

Нажмите Add to PATH

Нажмите Custom и протыкайте ОК

Закройте окно после успешной установки Python

# Установка модулей (для запуска)

Откройте PowerShell (администратор)

Введите туда cd (путь к папке)

pip install -r requirements.txt

Дождись установки модулей и закрой окно

# Запуск

Перейди в папку с проектом

Запусти zapusk.bat
